# Manual de usuario

`user-manual.pdf` es el manual de usuario oficial de Boot-Tracker, entregado al cliente.
Cubre web y mobile para los cinco roles (Salesperson, Bootcamper, Administrator,
Coordinator y Finance).

Se mantiene también embebido como Annex F en el informe final (`doc_ing2_2p`), este
archivo es la copia versionada de origen.
